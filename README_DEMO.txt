CLIENTFLOW CRM — STANDALONE DEMO

QUICK START
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, or another modern browser.
3. Choose Create Account and enter your name, email, and password (minimum 8 characters).
4. Accept the terms, finish the onboarding questions, and use the dashboard.
5. Log out and sign in again using the same email and password.

IMPORTANT LIMITATIONS
- This is a browser-only demo. No Node.js server or MySQL database is needed.
- Accounts and demo CRM records are saved in this browser's local storage. They do not sync between computers, browsers, or users.
- This is not production authentication: browser storage can be inspected or modified. Do not use real customer data or real passwords.
- CRM demo data is shared within this browser profile between demo accounts.
- For a public multi-user app with separate accounts and shared online access, a hosted backend and database are required.
